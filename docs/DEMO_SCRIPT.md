# 180 秒比赛演示

- 0—20 秒：低 C/N 尾水常依赖外加碳源；S-Fe 探索以硫铁复合自养路径深度脱氮除磷，S-Proof 管理运行与证据。
- 20—45 秒：背景成果丰富并不等于所有链条完整。首页明确区分背景证据和学生新增，先讲边界再讲数字。
- 45—90 秒：打开六批背景送样数据，展示 TN 与 NO₃⁻-N 浓度削减复算，以及黄色“第三方实验室送样，不等于第三方现场采样”标签；指出 `<0.003` 按检出限保守上界处理。
- 90—125 秒：运行质量检查，展示采样链、流量、质量平衡与 N₂O 缺口；MRV 保持 `indeterminate`，不把缺口默认为零。
- 125—155 秒：输入“世界首创的零碳系统”，Claim Gate 拦截并给出可用受限改写。
- 155—180 秒：生成证书并公开验证；修改输入会失败。总结学生新增的是可追溯软件闭环，证书不证明采样真实性或算法科学正确性。
