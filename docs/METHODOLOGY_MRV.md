# Screening MRV methodology

功能单位支持“处理 1 m³ 低 C/N 尾水并达到相同出水目标”，并可辅助报告去除 1 kg TN。情景排放为各活动量与版本化排放因子乘积之和，净筛选差值为基准排放减项目排放。

基准边界包括碳源、除磷药剂、电力、反冲洗、污泥和 N₂O；S-Fe 边界包括硫磺、铁材料、黏结剂/成孔剂、介体/启动剂、电力、反冲洗、填料更换、含铁沉淀/污泥和 N₂O。输出保留贡献项、活动等级、因子来源、缺失项及低/中/高敏感性。

只要 N₂O 未处理、关键活动缺失或存在占位因子，状态即为 `indeterminate`，不得显示确认减排。`0.402 vs 46.451 gCO₂/m³` 仅可登记为 legacy screening 背景，不能成为当前结果。
